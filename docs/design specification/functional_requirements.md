# 在庫管理システム 機能要件定義書

## 1. 概要

### 1.1 目的

物品の在庫数を簡単に管理し、入庫・出庫を記録することで、現在の在庫状況を把握できるようにする。

### 1.2 対象ユーザー

担当者（社内利用を想定）。

### 1.3 利用環境

- PC ブラウザ（モダンブラウザ最新版）での利用を主に想定する。
- スマートフォン・タブレットでも操作できるよう、全画面でレスポンシブ対応を行う。

### 1.4 システムの主な機能

- 在庫一覧表示
- 入庫登録
- 出庫登録
- 品目マスタ管理（追加・編集・削除）
- アカウント作成
- ログイン
- ログアウト

## 2. 画面一覧

| No. | 画面名         | 概要                                       |
| --- | -------------- | ------------------------------------------ |
| 1   | 在庫一覧       | 全品目の現在在庫を一覧表示し、検索を行う   |
| 2   | 入庫登録       | 品目に対する入庫を登録し、在庫数を加算する |
| 3   | 出庫登録       | 品目に対する出庫を登録し、在庫数を減算する |
| 4   | 品目マスタ管理 | 品目の追加・編集・削除を行う               |
| 5   | アカウント作成 | 新規ユーザーがメールアドレス、パスワード、ユーザー名を登録する |
| 6   | ログイン       | 登録済みユーザーがメールアドレス、パスワードでログインする |

## 3. 共通要件

### 3.1 検索機能

以下の画面で品目名による部分一致検索を可能とする。

- 在庫一覧
- 品目マスタ管理

### 3.2 入力チェック

- 数量は 1 以上の整数で入力する。
- 必須項目が未入力の場合は登録不可とする。
- 不正値入力時はエラーメッセージを画面上に表示する。
- 日付は YYYY-MM-DD 形式で入力する。

### 3.3 データ削除方針

- 品目および入出庫履歴は物理削除を行う。
- 品目を削除した場合、関連する入出庫履歴も併せて削除される旨を確認ダイアログで提示する。

### 3.4 認証

- 認証基盤は Supabase Auth を使用する。
- 新規ユーザーはアカウント作成画面から自己登録できる。
- 自己登録で作成されるユーザーの初期権限は `general` 固定とし、管理者、MG、一般のロール別に画面・操作を制御する。
- 登録済みユーザーはメールアドレスとパスワードでログインできる。
- 在庫一覧、入庫登録、出庫登録、品目マスタ管理などの業務画面はログイン済みユーザーのみアクセスできる。
- ログイン済みユーザーは業務画面のサイドバーからログアウトできる。

### 3.5 ロール別アクセス制御

- 管理者は在庫一覧、入庫登録、出庫登録、品目マスタ管理、ユーザー管理を利用できる。
- MGは在庫一覧、入庫登録、出庫登録、品目マスタ管理の閲覧を利用できる。
- 一般は在庫一覧のみ閲覧できる。
- 更新操作は Server Action / Route Handler 経由で実行し、サーバー側で操作ユーザーの権限を確認する。

## 4. 在庫一覧

### 4.1 表示項目

| 項目         | 説明                              |
| ------------ | --------------------------------- |
| 品目コード   | システム自動採番のコード          |
| 品目名       | 登録された品目名                  |
| カテゴリ     | 品目に紐づくカテゴリ（自由入力）  |
| 現在在庫数   | 入庫合計 − 出庫合計で算出         |
| 単位         | 個・本・箱 等、品目ごとに登録した値 |

### 4.2 機能

- 品目名による検索（部分一致）。
- 在庫数一覧表示（デフォルトは品目コード昇順）。

## 5. 入庫登録

### 5.1 概要

品目の入庫を登録し、対象品目の在庫数を加算する。

### 5.2 入力項目

| 項目     | 必須 | 形式・備考                            |
| -------- | ---- | ------------------------------------- |
| 品目     | 必須 | 登録済み品目から選択、または新規品目名を入力 |
| カテゴリ | 必須 | プルダウンから選択。既存品目選択時は既存カテゴリを反映 |
| 単位     | 必須 | プルダウンから選択。既存品目選択時は既存単位を反映 |
| 入庫数量 | 必須 | 1 以上の整数                          |
| 入庫日   | 必須 | YYYY-MM-DD（デフォルトは当日）        |
| 備考     | 任意 | 自由記述（例: 仕入先メモ等）          |

### 5.3 登録結果

- 登録後、対象品目の現在在庫数が入庫数量分加算される。
- 登録した入庫データは入出庫履歴として保存される。
- 新規品目名を入力した場合は、選択されたカテゴリと単位で品目マスタに品目を追加したうえで入庫履歴を保存する。

## 6. 出庫登録

### 6.1 概要

品目の出庫を登録し、対象品目の在庫数を減算する。

### 6.2 入力項目

| 項目     | 必須 | 形式・備考                            |
| -------- | ---- | ------------------------------------- |
| 品目     | 必須 | 登録済み品目から選択                  |
| 出庫数量 | 必須 | 1 以上の整数                          |
| 出庫日   | 必須 | YYYY-MM-DD（デフォルトは当日）        |
| 備考     | 任意 | 自由記述（例: 出庫先メモ等）          |

### 6.3 バリデーション

- 現在在庫数を超える出庫は登録不可とする。エラーメッセージを表示する。

### 6.4 登録結果

- 登録後、対象品目の現在在庫数が出庫数量分減算される。
- 登録した出庫データは入出庫履歴として保存される。
## 7. 品目マスタ管理

### 7.1 管理項目

| 項目       | 必須 | 形式・備考                              |
| ---------- | ---- | --------------------------------------- |
| 品目コード | 自動 | システムが自動採番（一意）              |
| 品目名     | 必須 | 自由入力（重複は許容しない方針が望ましい） |
| カテゴリ   | 任意 | 自由入力テキスト                        |
| 単位       | 必須 | 自由入力（例: 個、本、箱）              |

### 7.2 機能

- 品目追加
- 品目編集（品目コードは編集不可）
- 品目削除（関連する入出庫履歴がある場合は確認ダイアログを表示し、承認後に履歴ごと削除）

## 8. 受け入れ基準

1. 在庫一覧で品目名による検索ができる。
2. 入庫登録により、対象品目の在庫数が登録数量分加算される。
3. 出庫登録により、対象品目の在庫数が登録数量分減算される。
4. 現在在庫数を超える出庫は登録できない。
5. 品目の追加・編集・削除ができる。品目コードはシステムが自動採番する。
6. 必須項目が未入力／数量が不正値の場合、登録できずエラーメッセージが表示される。
7. 新規ユーザーがアカウントを作成できる。
8. 作成したアカウントでログインできる。

## 9. 想定外（本リリースのスコープ外）

将来的に検討する可能性があるが、本リリースでは対象外とする項目を明示しておく。

- 入出庫履歴の一覧画面・絞り込み検索
- 入出庫履歴の編集
- 在庫不足アラート（最低在庫数の閾値設定）
- カテゴリのマスタ管理
- CSV 等のデータエクスポート／インポート
- 複数倉庫・ロット管理などの拡張
